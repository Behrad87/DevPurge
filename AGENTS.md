# Agent Instructions & Workflow Rules

## Daily Git & Delivery Policy
- **Automated / End-of-Job Push**: Always stage, commit, and push every change to GitHub (`origin`) upon finishing work tasks daily.
- **Commit Standards**: Use clean, descriptive conventional commits (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`).
- **Safety**: Ensure code builds and tests succeed before pushing.
